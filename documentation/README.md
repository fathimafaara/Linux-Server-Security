# Linux Server Security & Access Control Management System

## Project Overview

This project focuses on configuring and securing an Ubuntu Linux server using essential Linux system administration and security practices.

This project demonstrates user and group management, file permissions, role-based access control, SSH security, firewall configuration, and security auditing.

## Objectives

- Manage Linux users and groups.
- Configure file ownership and permissions.
- Implement role-based access control.
- Secure SSH access.
- Configure firewall protection using UFW.
- Perform basic server security auditing.

## Environment

- Operating System: Ubuntu Server 26.04.1 LTS
- Virtualization: Oracle VirtualBox
- Access Control: chmod, chown, ACL
- SSH: OpenSSH
- Firewall: UFW

## Project Status

Core security configurations and inital security auditing completed.
