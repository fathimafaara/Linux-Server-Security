# File Permission and Access Control

## Project Directories

- configurations
- documentation
- testing

## Permissions

All three directories use permission 770.

## Ownership

- configurations: ubuntu / server_admins
- documentation: ubuntu / developers
- testing: ubuntu / developers

## Commands Used

- chmod
- chown
- setfacl
- getfacl

## Purpose

To protect project directories and allow only access to authourized users.
